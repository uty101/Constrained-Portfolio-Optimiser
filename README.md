# Constrained Portfolio Optimiser and Trade Generator

A walk-forward study of 6 allocators plus an equal-weight benchmark on 18 US-listed multi-asset ETFs, 2010 to 2026.
It measures how much of the in-sample gap between allocators survives out of sample once estimation error is included.
It prices a turnover limit in ex-ante return given up against trading cost saved.
It compares 4 covariance estimators by QLIKE and bias ratio, and tests how shrinkage and Black-Litterman steady mean-variance weights.
A CLI, `pctrade`, turns a positions file and a target strategy into a trade list for the fund.
