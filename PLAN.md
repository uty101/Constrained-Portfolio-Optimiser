# PLAN.md — Constrained Portfolio Optimiser and Trade Generator

This plan expands Section 8 of `instructions/00_kickoff.md` step by step. The kickoff document is the specification: methods (its Section 5), conventions (Section 4), signatures and schemas (Section 6) and parameters (`config.toml`, Section 7) are fixed there and are not restated in full here. Session N builds all of Section N below and nothing else. Every step is one commit, `step N.M: <one line>`. Every section ends with `review/section_N.md` (following `review/TEMPLATE.md`), the fresh-clone check of rule 12, and `instructions/NN_<name>.status.md`.

Points the kickoff left unspecified were raised in `instructions/00_kickoff.status.md` and `instructions/01_section_1.status.md`. The reviewer's decisions are in `decisions/section_0_review.md` and `decisions/section_1_review.md` and are written into the steps below. Any new gap goes to `decisions/OPEN.md` under rule 1.

## Section 1 — Data, calendar and returns

**1.1 Config.** Builds `pc/config.py` implementing `Config` (frozen dataclass, one field per `config.toml` key, one nested frozen dataclass per table: `run`, `universe`, `sample`, `data`, `cov`, `mv`, `costs`, `bl`, `solver`, `cov_eval`, `bootstrap`, `sensitivity`, `turnover_grid`, `positions`, `cli`, `outputs`) and `load_config(path: str | Path = "config.toml") -> Config`, reading with the standard library `tomllib`. Ticker-keyed tables (`universe.asset_class`, `costs.one_way_bp`, `bl.w_mkt`) are held in config ticker order. Tests in `tests/test_config.py`: `test_config_keys_match_fields` (every key in `config.toml`, walked recursively, is a field of `Config` and every field of `Config` is a key in `config.toml`); `test_w_mkt_sums_to_one` (|Σ w_mkt − 1| ≤ 1e-12); `test_one_way_bp_tickers` (`one_way_bp` has exactly the 18 configured tickers, no more, no fewer). Outputs: none. Review evidence: the loaded `Config` printed, and the full pytest output for the file.

**1.2 Data pull.** Builds `scripts/pull_data.py`, the only network code in the repo. It downloads daily adjusted closes for the 18 tickers from yfinance (`auto_adjust=True`) from `sample.price_start` to `sample.price_end` inclusive, and DGS3MO from `https://fred.stlouisfed.org/graph/fredgraph.csv?id=DGS3MO` over the same range. It writes `data/raw/prices_adjclose.csv` (date plus the 18 tickers in config order), `data/raw/rf_dgs3mo.csv` (date, DGS3MO as published, blanks kept), and `data/raw/MANIFEST.json` (pull timestamp UTC, yfinance version, row counts, first and last date per ticker, sha256 per data file). It is run once and the three files are committed. If yfinance or FRED fails, the section stops under rule 4; no alternative source is used. Test in `tests/test_manifest.py`: `test_manifest_hashes_match` (sha256 of each committed data file equals the manifest entry; reads only `data/raw/`). Outputs: the three `data/raw/` files. Review evidence: `MANIFEST.json` in full, the first and last 5 rows of each CSV via `to_string()`, and per-ticker first and last dates.

**1.3 Loaders and validation.** Builds `pc/data.py` implementing `load_prices(cfg) -> pd.DataFrame` (daily adjusted close, trading days only, 18 columns in config order, rows before the panel start dropped where panel start is the first date on which all 18 have a price, no NaN from the panel start), `load_rf_daily(cfg, index) -> pd.Series` (name `rf`, daily decimal on trading day d = DGS3MO(d−1)/100/252, forward filled across FRED gaps, aligned to `index`) and `validate_prices(prices, cfg) -> pd.DataFrame` (issues table with columns date, ticker, issue, value). Issues are reported and never fixed: |daily return| > `data.max_abs_daily_return_flag` (0.25), a gap between consecutive trading days > `data.max_gap_days_flag` (4) calendar days, any non-positive price, any duplicate date. Tests in `tests/test_data.py`: `test_load_prices_shape_and_order`, `test_load_prices_no_nan_from_panel_start`, `test_panel_start_is_first_full_row`, `test_rf_uses_previous_day_and_ffill` (synthetic series with a gap), `test_validate_flags_each_issue_type` (synthetic prices carrying one of each issue). Outputs: `outputs/tables/data_issues.csv`. Review evidence: the panel start date, the full `data_issues.csv` via `to_string()`, and the rf series around one FRED holiday gap.

**1.4 Calendar.** Builds `pc/calendar.py` implementing `build_calendar(prices_index, cfg) -> pd.DataFrame` with columns decision_date (last trading day of each month from `sample.first_decision` to `sample.last_decision`), exec_date (next trading day), next_exec_date (the following row's exec_date; for the last row, the first trading day after the 2026-08 month end, which is the first trading day of September 2026) and n_hold_days (trading days in (exec_date, next_exec_date]), on a RangeIndex, 196 rows. Tests in `tests/test_calendar.py`: `test_calendar_has_196_rows`, `test_first_decision_2010_04_30`, `test_last_decision_2026_07_31`, `test_exec_date_is_next_trading_day`, `test_decision_dates_are_trading_days`. Outputs: none. Review evidence: first and last 5 calendar rows via `to_string()`.

**1.5 Returns.** Builds `pc/returns.py` implementing `daily_returns(prices)`, `monthly_excess_returns(prices, rf_daily)` (calendar month-end close to month-end close simple returns minus compounded daily rf over the month; month-end index), `holding_returns(prices, cal)` (index decision_date, gross asset returns exec_date close to next_exec_date close) and `holding_rf(rf_daily, cal)` (compounded daily rf over the holding days). Tests in `tests/test_returns.py`: `test_compounded_daily_equals_holding_return` (to 1e-12); `test_rf_constant_5pct_gives_005_over_252` (synthetic constant 5% yield gives 0.05/252 per day); `test_monthly_excess_2020_03_manual` (monthly excess return for 2020-03 equals a manual calculation from the raw month-end closes and daily rf). Outputs: none. Review evidence: the manual 2020-03 calculation printed in full (the two month-end closes per ticker, compounded rf, and the result) next to the function output via `to_string()`.

**1.6 Data summary.** Writes `outputs/tables/data_summary.csv` (ticker, first_date, last_date, n_days, ann_return, ann_vol, worst_day, worst_date, best_day, best_date) and `outputs/tables/corr_full_sample.csv` (full-sample correlation of daily returns, tickers in config order) from `pc/data.py` and `pc/returns.py` outputs, via a function in `pc/data.py`. Annualisation is geometric: ann_return = (Π(1 + r_d))^(D/n) − 1 and ann_vol = std(r_d, ddof=1) × √D, D = 12 × `sample.days_per_month` (252), n the number of daily returns (`decisions/section_1_review.md` item 1). Test in `tests/test_data.py`: `test_data_summary_columns_and_rows` (18 rows, exact columns, config order). Outputs: the two CSVs. Review evidence: `data_summary.csv` in full via `to_string()`; `corr_full_sample.csv` in full.

## Section 2 — Covariance estimators and forecast evaluation

**2.1 Window, sample covariance, conditioning.** Builds in `pc/cov.py`: `window_daily(returns_d, t, months) -> pd.DataFrame` (daily rows with date in (t − months, t], exclusive start, inclusive end), `cov_sample(X) -> pd.DataFrame` (`np.cov(X, rowvar=False, ddof=1)`, daily) and `condition_cov(S, max_cond) -> tuple[pd.DataFrame, dict]` (if cond(S) > max_cond add r·I with r = max(0, (λ_max − max_cond·λ_min)/(max_cond − 1)); dict holds cond_before, cond_after, ridge; logged on every call). Tests in `tests/test_cov.py`: `test_window_boundaries_exclusive_start_inclusive_end` (synthetic index); `test_ridge_sets_cond_to_1e6` (synthetic matrix with cond 1e9 brought to 1e6 within 1e-6 relative); `test_condition_cov_noop_when_well_conditioned`. Outputs: none. Review evidence: the synthetic cond before and after and r, printed.

**2.2 Ledoit-Wolf estimators.** Builds in `pc/cov.py`: `cov_lw_cc(X, ddof=0) -> tuple[pd.DataFrame, float]` (Ledoit-Wolf 2004 constant-correlation shrinkage by hand as in kickoff 5.2, returns daily Σ and δ*; ddof 0 in production, ddof 1 only for the cross-check) and `cov_lw_identity(X) -> tuple[pd.DataFrame, float]` (shrinkage to scaled identity by hand, test use only). Tests in `tests/test_cov_lw.py`: `test_lw_cc_matches_pypfopt` (`cov_lw_cc(X, ddof=1)` equals PyPortfolioOpt `CovarianceShrinkage(X, returns_data=True, frequency=1).ledoit_wolf("constant_correlation")` and its `delta` to 1e-10); `test_lw_identity_matches_sklearn` (equals `sklearn.covariance.LedoitWolf(assume_centered=False)` covariance and shrinkage to 1e-10); `test_lw_cc_delta_in_unit_interval` (δ in [0, 1] on 50 random windows from the real data, drawn with seed `run.seed_master` as `default_rng(seed).choice(196, size=50, replace=False)` over the calendar's decision dates in order, each window `window_daily(returns_d, t, 36)`). A cross-check failure beyond tolerance stops the section under rule 4. Outputs: none. Review evidence: max absolute differences against both reference libraries and the 50 δ values via `to_string()`.

**2.3 EWMA.** Builds `cov_ewma(X, lam) -> pd.DataFrame` in `pc/cov.py`: Σ = Σ_k w_k r_{t−k} r_{t−k}′, w_k = (1 − λ) λ^k / (1 − λ^n), n = rows in the window, no demeaning, λ = `cov.ewma_lambda` (0.97, applied to daily data). Tests in `tests/test_cov.py`: `test_ewma_weights_sum_to_one`; `test_ewma_lambda_near_zero_is_last_outer_product` (λ = 1e-12 equals the outer product of the last row). Outputs: none. Review evidence: weight sum and the λ → 0 max abs difference, printed.

**2.4 PCA.** Builds `cov_pca(X, k) -> pd.DataFrame` in `pc/cov.py`: R sample correlation, eigendecompose, R_f = V_kΛ_kV_k′ + diag(1 − diag(V_kΛ_kV_k′)), Σ = D R_f D with D the sample vols, k = `cov.pca_k` (3). Tests in `tests/test_cov.py`: `test_pca_rf_unit_diagonal`; `test_pca_positive_definite`; `test_pca_full_rank_equals_sample` (k = N equals the sample covariance to 1e-10). Outputs: none. Review evidence: minimum eigenvalue of the k = 3 estimate on one real window and the k = N max abs difference.

**2.5 estimate_cov and GMV.** Builds `estimate_cov(returns_d, t, name, cfg) -> tuple[pd.DataFrame, dict]` in `pc/cov.py` (dispatch on name in `cov.estimators`, window of `sample.window_months`, daily × `sample.days_per_month`, then `condition_cov` with `cov.max_cond`; returns the monthly conditioned Σ and the log dict) and `gmv_closed_form(Sigma) -> pd.Series` in `pc/risk.py` (Σ⁻¹1/(1′Σ⁻¹1) via `np.linalg.solve`). Tests in `tests/test_cov.py`: `test_monthly_is_daily_times_21_exactly`; `test_conditioning_log_fields_always_present` (cond_before, cond_after, ridge present for every estimator, whether or not a ridge was applied); `tests/test_risk.py::test_gmv_closed_form_sums_to_one`. Outputs: none. Review evidence: the log dict for each estimator at the first decision date.

**2.6 Covariance forecast evaluation.** Builds `pc/cov_eval.py` running every estimator at all 196 decision dates on 3 portfolio sets held fixed over the holding period: `ew` (1/N), `gmv` (budget-only closed form from that estimator), `random` (`cov_eval.n_random` = 100 long-only Dirichlet(1,…,1) portfolios drawn once with seed `run.cov_eval_seed`, the same at every date). Forecast variance = w′Σw × n_hold_days/21; realised variance = Σ_d (w′r_d)²; holding return r_h = Σ_d w′r_d. QLIKE = log σ̂² + σ²_realised/σ̂², averaged over dates (and over the 100 portfolios for `random`). Bias ratio = std(r_h/σ̂_h, ddof=1) over dates, with the 90% band 1 ± 1.645√(1/(2n)). QLIKE differences against `lw_cc` use the stationary block bootstrap of kickoff 5.8 (mean block 6, 10,000 reps, seed `run.bootstrap_seed`) with a 90% interval; this step implements `stationary_bootstrap_indices(n, mean_block, reps, seed) -> np.ndarray` in `pc/stats.py` for that purpose. Tests in `tests/test_cov_eval.py`: `test_random_portfolios_fixed_and_long_only` (same 100 at every date, nonnegative, sum to 1); `test_qlike_on_synthetic_perfect_forecast`; `test_bias_band_formula`; `tests/test_stats.py::test_bootstrap_indices_shape_and_determinism` (reps × n, values in [0, n), same seed gives identical output). Outputs: `outputs/tables/cov_eval.csv` (estimator, portfolio_set, n, qlike_mean, bias_ratio, band_lo, band_hi, mean_cond_before, n_ridged; 12 rows) and `outputs/tables/cov_eval_qlike_diff.csv` (estimator, portfolio_set, diff_vs_lw_cc, p05, p95, frac_le_0). Review evidence: the 12 rows of `cov_eval.csv` via `to_string()`, the full `cov_eval_qlike_diff.csv`, and the first and last 5 dates of per-date QLIKE for `ew`.

## Section 3 — Allocators

**3.1 Solver, constraint types and feasibility.** Builds `pc/solver.py` (cvxpy with `solver.primary` CLARABEL; on any status other than `optimal`, one retry with `solver.fallback` SCS at `eps = solver.scs_eps`; if SCS is not `optimal`, the caller receives a fallback signal and the allocator returns drifted `w_prev` with `fallback = True` and the status string; every call records solver, status, fallback), the `Constraints` and `AllocResult` dataclasses in `pc/allocators.py` exactly as in kickoff Section 6, and the set C feasibility LP: τ_min = min ‖w − w_prev‖₁ s.t. 1′w = 1, 0 ≤ w ≤ upper; if τ_min > τ, solve with τ_eff = τ_min + 1e-6 and record `tau_relaxed = True` and τ_eff. Tests in `tests/test_solver.py`: `test_tau_relaxed_when_drifted_weight_above_cap` (drifted weight 0.45 against a 0.30 cap and τ = 0.05 sets `tau_relaxed = True` and τ_eff = 0.30 + 1e-6 within 1e-8); `test_tau_not_relaxed_when_feasible`; `test_fallback_returns_w_prev_on_solver_failure`. Outputs: none. Review evidence: the synthetic τ_min, τ_eff and flags printed.

**3.2 Risk contributions.** Builds in `pc/risk.py`: `risk_contributions(w, Sigma) -> pd.Series` (RC_i = w_i(Σw)_i/√(w′Σw)) and `pct_risk_contributions(w, Sigma) -> pd.Series` (RC_i/√(w′Σw)), pure numpy/pandas with no import from the rest of `pc/` (project 4 imports them). Tests in `tests/test_risk.py`: `test_rc_sums_to_fund_vol` (to 1e-12); `test_euler_identity` (w′∂σ/∂w = σ, gradient by analytic formula checked against the sum); `test_risk_module_imports_nothing_from_pc`. Outputs: none. Review evidence: RC vector and fund vol for one synthetic case.

**3.3 Mean-variance unconstrained and minimum variance.** Builds in `pc/allocators.py`: `mv_unconstrained(mu, Sigma, w_prev, cons) -> AllocResult` (set A closed form w = (1/γ)Σ⁻¹(μ − η1), η = (1′Σ⁻¹μ − γ)/(1′Σ⁻¹1), γ = `mv.gamma`, no solver) and `min_variance(mu, Sigma, w_prev, cons) -> AllocResult` (set B, min w′Σw, 1′w = 1, `mv.lower` ≤ w ≤ `mv.upper`, via `pc/solver.py`; μ accepted and not read). Tests in `tests/test_allocators.py`: `test_mv_unconstrained_matches_cvxpy_budget_only` (to 1e-7); `test_budget_only_min_variance_matches_closed_form` (equals Σ⁻¹1/1′Σ⁻¹1 to 1e-7); `test_min_variance_set_b_respects_bounds` (to 1e-9). Outputs: none. Review evidence: max abs differences for each test, printed.

**3.4 Constrained mean-variance.** Builds `mv_constrained(mu, Sigma, w_prev, cons) -> AllocResult` in `pc/allocators.py`: max μ′w − (γ/2)w′Σw − c′|w − w_prev| s.t. set C (or set B when τ and costs are off), via cvxpy through `pc/solver.py`, with the feasibility rule from 3.1, reporting the dual value of the turnover constraint as `turnover_dual` (monthly return per unit of turnover; 0 when slack; NaN when there is no turnover constraint). Tests in `tests/test_allocators.py`: `test_mv_constrained_no_tau_no_cost_equals_set_b` (to 1e-7); `test_mv_constrained_kkt_stationarity` (residual < 1e-6 on a synthetic case); `test_turnover_dual_nonnegative_and_zero_when_slack` (≥ 0; within 1e-8 of 0 when slack); `test_turnover_never_exceeds_tau_eff` (≤ τ_eff + 1e-7). Outputs: none. Review evidence: the KKT residual, a binding and a slack case with turnover, τ_eff and dual (also shown in bp of monthly return per 1% turnover).

**3.5 Risk parity.** Builds `risk_parity(mu, Sigma, w_prev, cons) -> AllocResult` in `pc/allocators.py`: Spinu, minimise ½x′Σx − Σ_i b_i log x_i, b_i = 1/N, `scipy.optimize.minimize(method="L-BFGS-B")` with analytic gradient Σx − b/x, bounds (1e-12, None), x₀ = 1/√diag(Σ), `ftol = solver.rp_ftol`, `gtol = solver.rp_gtol`, `maxiter = solver.rp_maxiter`, w = x/1′x. Tests in `tests/test_allocators.py`: `test_risk_parity_equal_contributions_real_sigma` (pct risk contributions within 1e-6 of 1/N on the real Σ at 2010-04-30, 2012-12-31, 2016-06-30, 2020-02-28 and 2026-07-31, each with all 4 estimators through `estimate_cov`, 20 cases); `test_risk_parity_weights_positive_sum_to_one`. Outputs: none. Review evidence: pct risk contributions at the 5 dates via `to_string()`.

**3.6 HRP.** Builds `hrp(mu, Sigma, w_prev, cons) -> AllocResult` in `pc/hrp.py` by hand: d_ij = √(clip((1 − ρ_ij)/2, 0, 1)), `scipy.cluster.hierarchy.linkage(squareform(d), "single")` applied to d directly, quasi-diagonal order from `to_tree(link).pre_order()`, recursive bisection in halves with inverse-variance weights within each half and α = 1 − V₁/(V₁ + V₂). Tests in `tests/test_hrp.py`: `test_hrp_matches_pypfopt` (equals PyPortfolioOpt `HRPOpt(returns=X).optimize("single")` to 1e-10 when fed `X.cov()` and `X.corr()`); `test_hrp_hand_worked_4_asset` (a 4-asset example worked by hand in the test docstring, matching to 1e-12. Outputs: none. Review evidence: the max abs difference against PyPortfolioOpt and the hand-worked weights next to the function output.

**3.7 Expected returns, Black-Litterman, equal weight.** Builds `pc/returns_model.py` (`mu_sample(monthly_excess, t, months) -> pd.Series`, mean of the trailing 36 monthly excess returns ending at t; `mu_bayes_stein(mu_hat, Sigma, T) -> tuple[pd.Series, float]`, Jorion 1986 as in kickoff 5.1 with Σ the monthly LW covariance and T = `sample.window_months`), `pc/bl.py` (`implied_returns(Sigma, w_mkt, delta)`, Π = δΣw_mkt; `momentum_views(monthly_total, monthly_excess, t, cfg) -> tuple[pd.DataFrame, pd.Series]`, the two mechanical 12-1 views of kickoff 5.4 with ties broken by config order; `bl_posterior(Sigma, Pi, P, Q, tau) -> tuple[pd.Series, pd.DataFrame]`, Ω = diag(PτΣP′), μ_BL and Σ_BL via `np.linalg.solve`), a `black_litterman` allocator (mean-variance on μ_BL with Σ_BL, same objective and constraints as `mv_constrained`), and `equal_weight(mu, Sigma, w_prev, cons) -> AllocResult` (1/N) in `pc/allocators.py`. Tests in `tests/test_bl.py` and `tests/test_returns_model.py`: `test_bl_no_views_returns_pi`; `test_set_a_mv_on_pi_returns_w_mkt` (set A mean-variance on (Π, Σ) with γ = δ returns w_mkt to 1e-8, using Σ, not Σ_BL); `test_bl_tiny_omega_satisfies_views` (Ω scaled by 1e-10 gives Pμ_BL = Q to 1e-6); `test_momentum_views_ties_by_config_order`; `test_bayes_stein_phi_in_unit_interval`; `test_bayes_stein_constant_mu_unchanged`; `test_equal_weight_is_one_over_n`. Outputs: none. Review evidence: P, Q, Π and μ_BL at the first decision date via `to_string()`, and φ at the first decision date.

## Section 4 — Walk-forward and headline results
